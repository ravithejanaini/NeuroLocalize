## Not used, and why

- **StatPearls — Anatomy, Shoulder and Upper Limb, Nerves (NBK526056).** Obtained only as a
  paraphrased table, which gave the axillary nerve C5–T1 and had the lower subscapular nerve
  supply teres minor — both at odds with S42 and S33. A summary that cannot be checked
  against its source is not cited.
- **StatPearls — Thoracic Outlet Syndrome (NBK557450).** Read. It names the Gilliatt-Sumner
  hand but does not say which part of the plexus is compressed, so it supports nothing
  modelled.
- **"A C8 radiculopathy weakens the thenar muscles."** This appeared in a summary of S38 but
  not in S38's text when read verbatim. Not cited (R15).
- **Sensory nerve action potentials in root versus plexus lesions.** A summary of S37 said
  so; S37 read verbatim does not. Not cited, and not modelled: this tool models the bedside
  examination, not electrodiagnosis.
- **Brazis, *Localization in Clinical Neurology*; Blumenfeld, *Neuroanatomy Through Clinical Cases*.**
  The plan named them. Neither was available to read, and a page number that was not read
  is an invented citation. Every row carries `bookRef: 'pending'` for a reviewer who owns
  the books. See D1 in `DECISIONS.md`.
- **ISNCSCI worksheet.** Copyright forbids alteration; reshaping it into software is a
  derivative work. Cited nowhere as data.
- **Lee, McPhee & Stringer 2008.** Known only through S21's description of it. Not read.
- **PMID 23649511** (lumbosacral segment positions against vertebral bodies). Seen only as a
  search-engine summary, so not cited. S14 carries the conus mapping instead.
- **The bulbocavernosus reflex's segmental level** was seen only in a search-engine summary.
  The row is marked `pending` rather than cited.
