Is this what a student should be taught?

NeuroLocalize is a teaching tool for localising lesions, from the cortex to the nerves of the hand. Every finding it shows is computed from the claims below, and each claim cites the open-access sources it was taken from. Nobody with clinical training has checked them yet. That is what this page asks of you.

Mark each claim right, wrong or not sure. Where something is wrong, a one-line correction with a source (a textbook and page is ideal) is the most useful thing you can give. Claims are ordered by how much of the tool rests on them, so the first twenty matter most; stopping part-way is fine.

Your answers stay in this browser as you go. When you have finished, or want to stop, press Save review to a file and send the file back to whoever sent you this page.

Claims the tool computes from

Each is a row in the knowledge base. “Weight” is how many expected findings fail when the claim is deliberately corrupted, so it measures how much depends on it. A tier of T3 means the sources disagree and both positions are kept.

    Facts the tool draws

    These change no computed finding, but they are drawn or printed: positions, myotomes, dermatome landmarks, fibre speeds and tract arrangement.

      Open questions

      Places where no source read settled the matter and a modelling choice was made. Right means the choice is sound; wrong means it should change, and the note should say how.

        What the tool teaches for each lesion

        These findings are stated by no single source; they follow from several claims together, which makes them the likeliest place for a reasoning error. Flag any line that is wrong, then give the case a verdict.
